# 🏡 House Prices Prediction & Real Estate Analytics Dashboard

An end-to-end Data Analytics & Machine Learning project built on the King County House Sales dataset.

This project combines:

- 📊 Business Intelligence using Power BI
- 🧹 Data Cleaning & Feature Engineering
- 🤖 Machine Learning Regression Models
- 📈 Investment Opportunity Analysis

---

# 📌 Project Overview

The objective of this project is to analyze the housing market, identify investment opportunities, and build machine learning models capable of predicting house prices.

The project covers the complete analytics workflow:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Hyperparameter Tuning
- Model Evaluation
- Interactive Power BI Dashboard

---

# 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- XGBoost
- CatBoost
- SQL Server
- Power BI

# 📊 Power BI Dashboard

The dashboard contains three interactive pages.

## Executive Overview

- Total Houses
- Average Price
- Average Grade
- Average Condition
- Average Living Area
- Monthly Sales Trend
- Interactive Filters

---

## Market Analysis

Provides insights into the housing market including:

- Price Distribution
- Grade Distribution
- Condition Analysis
- Geographic Price Map
- Underpriced vs Overpriced Houses

---

## Investment Analysis

Designed for real estate investors.

Includes:

- Top ROI Houses
- Price Categories
- Monthly Sales Trend
- Investment Opportunity Identification

---

# 🤖 Machine Learning Models

Three regression models were developed and compared.

- Linear Regression
- XGBoost Regressor
- CatBoost Regressor

Hyperparameter tuning was performed using **GridSearchCV**.

Evaluation Metrics:

- RMSE
- R² Score

The trained models are exported as:

- xgb_best_model.pkl
- catboost_best_model.pkl
